# AGENTS.md

This repository's guidance for coding agents lives in [CLAUDE.md](./CLAUDE.md).

Read that file before making changes here — it covers what this repo is, how recipes are
structured, the Temporal/Python architecture conventions recipes follow, CI requirements
(including the README front matter every recipe needs), and the README style guide used
when recipes are published to docs.temporal.io.

`CLAUDE.md` is the single source of truth; this file exists only so agents that look for
`AGENTS.md` instead of `CLAUDE.md` find their way to the same guidance.
